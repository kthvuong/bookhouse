Privacy & Lock

A 4-digit PIN screen so a stranger with your hosted link can't casually browse your journal. This runs entirely in your browser — it's a deterrent, not bank-grade security.

Forgot it? Open your browser's console on this page and run localStorage.clear(), then refresh — you'll be asked to set a new PIN. Your library itself lives in IndexedDB and is untouched by this.

Book Search

Cover art and search results come from Google Books, with Open Library as a backup. Google's free search has a small shared quota that can run out under heavy public traffic — adding your own free API key gives you a private quota so search stays reliable.

How do I get a free key?
  1. Go to the Google Cloud Console's Books API page and click "Enable" (create a project first if prompted — it's free).
  2. Go to Credentials and click "Create Credentials" → "API key".
  3. Copy the key it gives you and paste it above. Optionally click "Restrict key" and limit it to the Books API only.

Sync

Your library lives in this browser by default, so a different device starts empty. Paste the sync token below (once per device) to keep everything — books, ratings, progress, goals — the same everywhere. This is whole-library sync: whichever device syncs most recently wins, so it isn't built for editing the same book on two devices at once.

Backup & Export

Your reading data lives entirely in this browser. Back it up regularly — it never depends on Open Library staying available.

Restoring replaces everything currently in your library with the contents of the backup file.
